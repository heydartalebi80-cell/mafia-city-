# Mafia City

A 3D multiplayer mafia and city management game for Android.

## Languages
- Persian
- English

## Planned Features
- 6, 8 and 10 player rooms
- Mafia, Citizen, Doctor and Detective roles
- Text chat and voting
- League and rankings
- City development and economy
- Shop, coins, diamonds and VIP

## Development
The project will be developed in stages. Online gameplay requires a secure server.
